## 💀 Sistema de Boss

Quando o boss aparece, o jogo muda de clima.

A maçã principal dá lugar a uma **caveira**, a interface fica mais sombria e o jogador precisa causar dano antes do tempo acabar.

O boss foi pensado para quebrar a rotina do clicker e criar um momento de tensão, recompensa e desafio.

### Durante o boss:

- a maçã vira uma caveira;
- o visual fica mais sombrio;
- o jogador causa dano clicando;
- existe vida, tempo e recompensa;
- o jogo volta ao normal ao finalizar.

## 🛠️ Como publicar no GitHub Pages

Suba estes arquivos na raiz do repositório:

- `index.html`
- `style.css`
- `script.js`
- `manifest.webmanifest`
- `sw.js`
- `README.md`

Depois vá em:

```txt
Settings → Pages → Deploy from a branch → main → /root
```

Importante:  
Não coloque o projeto dentro de uma pasta extra. O arquivo `index.html` precisa ficar diretamente na raiz do repositório.

## 🧪 Observação sobre cache

Depois de atualizar o jogo no GitHub Pages, pode ser necessário limpar cache no navegador.

No PC:

```txt
Ctrl + F5
```

No celular:

```txt
Limpar dados do site ou abrir em aba anônima
```

Também é recomendado versionar os arquivos no HTML:

```html
<link rel="stylesheet" href="style.css?v=10.4.0">
<script src="script.js?v=10.4.0"></script>
```
