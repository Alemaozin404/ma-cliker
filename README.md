## 💀 Sistema de Boss

Quando o boss aparece, o jogo muda de clima.

A maçã principal dá lugar a uma **caveira**, a interface fica mais sombria e o jogador precisa causar dano antes do tempo acabar.

O boss foi pensado para quebrar a rotina do clicker e criar um momento de tensão, recompensa e desafio.

### Durante o boss:

- a maçã vira uma caveira;
- o visual fica mais sombrio;
- o jogador causa dano clicando;
- existe vida, tempo e recompensa;
- o jogo volta ao normal ao finalizar.
